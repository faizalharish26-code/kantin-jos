# kantin-jos

Aplikasi manajemen dan pemesanan kantin berbasis web untuk mempermudah transaksi, pengelolaan menu, dan pemrosesan pesanan secara *realtime*.

---

## 📋 Requirements

Sebelum memulai, pastikan perangkat Anda telah terpasang dependensi berikut:

* **PHP** `>= 8.2`
* **Composer** `>= 2.x`
* **Node.js** `>= 18.x` & **NPM**
* **Database Engine** (MySQL / PostgreSQL / SQLite)
* **Extension PHP:** `bcmath`, `ctype`, `fileinfo`, `json`, `mbstring`, `openssl`, `pdo`, `tokenizer`, `xml`
